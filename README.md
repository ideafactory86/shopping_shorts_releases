# IDEA FACTORY 쇼핑쇼츠 제작기 업데이트

Windows 실행 파일 배포 전용 저장소입니다.

- 앱의 관리 · 도움말 → 업데이트 확인에서 새 버전을 확인합니다.
- 다운로드된 실행 파일은 GitHub 배포 SHA-256과 대조한 뒤 설치합니다.
- 설정·작업 기록·원본·로컬 모델은 업데이트 파일에 포함하지 않습니다.
- 시작 확인에 실패하면 이전 실행 파일로 자동 복구합니다.
- 이 저장소에는 운영 데이터, API 키, 원본 상품 영상과 개발 소스를 게시하지 않습니다.

현재 배포는 내부 검증판입니다. 고객용 설치·인증·결제 기능의 완료를 의미하지 않습니다.
